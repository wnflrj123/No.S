# No.S 기획서

## 프로젝트 개요

삼성전자 뮤지컬 동호회 "No.S(넘버에스)"의 내부 웹 플랫폼.
동호회원들이 회사 연습실 예약 현황을 공유하고, 동호회 행사를 안내받는 공간.

**핵심 전제**: 실제 예약은 회사 별도 시스템에서 진행됨. 이 사이트는 예약 정보를 "공유"하는 용도이며, 예약 충돌 체크는 불필요함.

## 디자인 컨셉

- 색상: 블루(#0066B3) & 화이트 기반
- 분위기: 밝고 화사한, 토스 스타일 UI
- 다크 모드 없음

## 사용자 역할

| 역할   | 설명                                                    |
| ------ | ------------------------------------------------------- |
| Owner  | 최고 관리자. 어드민 추가/삭제, 소유권 이전, 회원 동기화 |
| Admin  | 동호회 이벤트 CRUD, 일반 관리, 타인 예약 삭제           |
| Member | 예약 조회, 본인 예약 등록/수정/삭제                     |

- 모든 기능은 로그인(Google OAuth) 필수
- 예약 수정은 본인만 가능, 삭제는 본인 + Admin/Owner 가능

## 페이지 구성

### 1. 메인 페이지 (`/`)

- 랜딩 페이지 (히어로 섹션 + 공지사항 안내 + 동호회 소개 + 기능 안내)
- 로그인 여부에 따라 CTA 분기 (로그인 → 예약현황 / 비로그인 → 로그인)

### 2. 로그인 페이지 (`/login`)

- Google OAuth 로그인
- 인앱 브라우저 감지 (카카오톡, 네이버, 인스타그램 등) → 외부 브라우저 유도
- 로그인 완료 시 홈으로 리다이렉트

### 3. 예약 현황 페이지 (`/reservations`) — 핵심 기능

- **캘린더 뷰**: 월간 달력, 날짜별 예약 건수 뱃지(파란색) + 행사 뱃지(오렌지, 여러날 행사는 셀 간 연결 표시) + 정기 일정 뱃지(#4eaea9)
- **리스트 뷰**: 기간별 조회 (1주/2주/1개월/커스텀)
- **예약 등록**: 날짜, 시작·종료 시간, 장소, 목적 입력
- **반복 예약**: 요일 선택 + 종료일 설정, 최대 100건 일괄 생성
- **예약 삭제**: 반복 예약의 경우 3가지 옵션 (이것만/이후 전부/전체), Admin/Owner는 타인 예약 삭제 가능
- **이벤트 표시**: 관리자가 등록한 동호회 행사 (오렌지 색상 구분, 여러날 행사 지원)
- **정기 일정**: 아카데미, 정극 연습 등 공식 일정 (#4eaea9, Admin/Owner 전용, 반복 등록/수정/삭제 지원)
- **필터**: 이용 가능한 날 / 행사만 보기 / 정기 일정만 보기 토글
- **지도 링크**: 행사 장소에 네이버지도/카카오맵 등 외부 지도 링크 연동
- **실시간 업데이트**: Firestore onSnapshot으로 다른 사용자 변경 즉시 반영

### 4. 작품 정보 페이지 (`/musicals`)

- **캐러셀 뷰**: 등록된 뮤지컬 목록을 카드 슬라이더로 표시, 선택 시 미니 모드로 전환
- **상세 패널**: 씬/넘버 아코디언, 캐릭터 목록 표시
- **작품 등록/수정**: 작품명, 이미지 URL, 캐릭터 목록 (이름/축약어/설명), 씬·넘버 구성 (Admin 전용), Table 기반 붙여넣기 기능 지원

### 5. 프로덕션 페이지 (`/productions`)

- **목록 뷰**: 공연명, 기간, 연결된 뮤지컬, 스태프, 캐스팅 보드, 공연 회차 표시
- **상세 정보**: 회차별 캐스팅 (배역 ↔ 배우 매핑), 스태프 역할 (연출/음악감독/안무/무대감독)
- **등록/수정**: 공연명, 설명, 연결 뮤지컬, 공연 기간, 공연 장소, 스태프, 회차 및 캐스팅 구성 (Admin 전용)

### 6. 공지사항 페이지 (`/notices`)

- **목록 뷰**: 페이지네이션 (10건씩), 고정 공지 상단 표시
- **상세 뷰**: 리치 텍스트(HTML) 렌더링, 기존 플레인 텍스트 하위 호환
- **작성/수정**: 리치 텍스트 에디터 (TipTap 기반)
  - 글자 크기 (4단계), 볼드/이탤릭/밑줄/취소선
  - 글자 색상 (8종 프리셋 + 커스텀 색상 선택)
  - 텍스트 정렬 (좌/중/우), 불릿 리스트
  - 키보드 단축키 (Ctrl+B, Ctrl+I, Ctrl+U 등)
- **권한**: Admin만 작성/수정/삭제 가능

### 7. 관리 페이지 (`/admin`) — Owner 전용

- 어드민 추가/삭제 (이메일 검색)
- 소유권 이전 (확인 텍스트 입력 필수)
- 전체 회원 목록 (페이지네이션, 10건씩)
- Firebase Auth → Firestore 회원 동기화

### 8. 정기공연 신청 페이지 (`/invite/[year]/[round]`) — 외부 관객용

- **공개 정보 페이지** (`/invite/[year]/[round]`): 비로그인 접근, 포스터·공연 안내·회차별 캐스팅(탭)·제작진 소개(플레이빌 점선 리더) + 시간·장소(지도 임베드) + 신청 CTA
- **신청 페이지** (`/invite/[year]/[round]/apply`): 이름·휴대폰·회차별 인원·옵션 항목(폼별 on/off 가능), 동일 이름·전화번호 중복 시 supersede 흐름
- **신청 확인 페이지** (`/invite/[year]/[round]/check`): 이름·휴대폰으로 본인 신청 내역 조회 (회차+일시 표시)
- **감사 페이지** (`/invite/[year]/[round]/thanks/[token]`): 신청 완료 안내 + 후원 계좌 + "후원했어요" 버튼, 후원 후 폭죽·꽃잎·꽃다발 효과 (모바일 성능 최적화 — `animation-fill-mode: both`, fixed 컨테이너, 입자 수 절제)
- **후원자 Wall** (`/invite/[year]/[round]/wall`): 공연장 TV용 실시간 후원자 명단, "응원 꽃다발 보내기"로 현장 후원자 추가, 새 등장 시 셀러브레이션 오버레이(dim+블러+꽃다발)
- **회차별 마감**: 회차 시작 시각 지나면 그 회차 자동 비활성, 모든 회차 종료 시 신청 차단
- **관리자 페이지** (`/admin/invites`): 공연 CRUD(배역·제작진·회차 편집, 제작진 직책 순서 드래그), 공개 토글, 신청자 목록(검색·삭제·후원 토글)·통계·항목별 답변·후원자 모아보기(신청자/현장 후원자 통합, 현장은 추가/삭제 가능)
- **SMS 발송** (솔라피 LMS): 신청 완료 자동 발송 + 관리자 일괄 발송(전체/회차/후원자, 변수 치환)
- **데이터**: `invites` / `inviteRegistrations` / `inviteSupporters` / `smsLogs` 컬렉션, 캐스팅·포스터 사진은 `/public/invites/{year}-{round}/` 정적 파일
- **무료 한도**: Firestore Spark 한도 내, 이미지 대역폭은 Vercel CDN 활용

### 9. 송년 공연 페이지 (`/yearend/[year]`) — 외부 관객용

- **공개 프로그램 페이지**: 비로그인 접근. 2026년은 「우리의 525,600분」(3부 구성, 38곡, 출연 34명)
- **디자인**: Atlassian Design System 참고 — 브랜드 블루(#0C66E4), 액센트 세트(마젠타·틸·퍼플 등), 로젠지 배지, 원형 아바타, 아이콘 타일, raised/overlay 그림자, 4·8·12px 라운드. 글꼴은 Pretendard(jsDelivr CDN). 문구는 친근한 구어체 + 이모지
- **히어로**: 브랜드 블루 면 + 크리스마스 장식(트리 볼 오너먼트·선물 상자·캔디케인·별·반짝이는 전구 가랜드·눈 쌓인 언덕), 공연 제목 숫자(525,600)를 크게 보여 주고 로드 시 한 번 카운트업, 눈 내리는 효과 (모션 줄이기 설정이면 모두 멈춤). 일시·장소 카드, 부별 바로가기 카드
- **소개**: 서회장 인사 문구 + 해시태그
- **프로그램**: 1부 마젠타, 2부 틸, 3부 퍼플. 부마다 아이콘 타일·로젠지·제목, 연속된 곡은 흰 카드 하나에 목록으로(번호·곡명·분류 로젠지·출처·출연진), 이벤트(히든덕기·송별회·퇴임식과 대관식)와 창작 단막극은 떠 있는 카드
- **크레딧**: 단체곡은 연출·강사·반장을 로젠지로 먼저 보여 주고, 아래 출연진 목록(가나다순)에도 연출·반장 이름을 함께 넣는다. 밴드는 파트별, 단막극·라비보엠은 배역별 표기(라비보엠은 RENT 캐스팅 보드 순, 배역이 많으면 두 개씩 줄바꿈). 강사처럼 무대에 서지 않는 사람은 출연진 집계에서 제외
- **가족 무대**: 가족과 함께 서는 곡은 "💞 가족 무대" 배지 + 한 줄 설명
- **크리스마스 장식(본문)**: 옅은 눈송이 배경, 부마다 전구 가랜드, 오너먼트 모양 곡 번호, 이벤트 카드 캔디케인 띠, 푸터 "Merry Christmas & Happy New Year"
- **관객 신청**: 데이터의 `apply.url`(구글폼)이 있으면 히어로(1·2·3부 바로가기 아래) 금색 버튼 + 페이지 하단 크리스마스 신청 카드 표시, 비어 있으면 숨김
- **편의 기능**: 맨 위로 가는 플로팅 버튼, 스크롤하면 카드가 살짝 떠오르며 나타나는 효과(scroll-driven animation 지원 브라우저만, 모션 줄이기 설정이면 페이드만)
- **모바일**: 숫자 카운트업은 JS(requestAnimationFrame)로 그려 사파리에서도 동작, 장식은 모바일에서 화면 안쪽에 작게 배치, 제목은 `text-wrap: balance`·본문은 `pretty`, 긴 문구는 데이터의 `\n`으로 휴대폰 폭에 맞춰 줄바꿈. PWA 설치 안내 배너는 이 경로에서 숨김
- **출연진**: 총연출·MC(한 줄) + 가나다순 이름 그리드
- **오시는 길·관람 안내**: 일시, 장소·주소, 지도 임베드(허용 호스트만), 네이버·카카오 지도 링크, 관람 안내(로비 핑거푸드·주류, 객석은 음료만, 식사 불가, 주차 불가, 연말 텐션)
- **공유 미리보기 이미지**: `opengraph-image.tsx`가 빌드 때 1200×630 이미지를 만든다(Pretendard 글꼴, 전구·오너먼트 장식). 카카오톡 등에서 잘려도 되도록 핵심 정보는 가운데 약 620px 안에 둔다
- **데이터**: Firestore 없이 `lib/yearend/{year}.ts` 코드 데이터로 관리. 데이터 파일에 있는 연도만 페이지 생성(그 외 404)
