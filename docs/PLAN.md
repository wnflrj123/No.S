# No.S 기획서

## 프로젝트 개요

삼성전자 뮤지컬 동호회 "No.S(넘버에스)"의 내부 웹 플랫폼.
동호회원들이 회사 연습실 예약 현황을 공유하고, 동호회 행사를 안내받는 공간.

**핵심 전제**: 실제 예약은 회사 별도 시스템에서 진행됨. 이 사이트는 예약 정보를 "공유"하는 용도이며, 예약 충돌 체크는 불필요함.

## 디자인 컨셉

- 색상: 블루(#0066B3) & 화이트 기반
- 분위기: 밝고 화사한, 토스 스타일 UI
- 다크 모드 없음

## 사용자 역할

| 역할   | 설명                                                    |
| ------ | ------------------------------------------------------- |
| Owner  | 최고 관리자. 어드민 추가/삭제, 소유권 이전, 회원 동기화 |
| Admin  | 동호회 이벤트 CRUD, 일반 관리, 타인 예약 삭제           |
| Member | 예약 조회, 본인 예약 등록/수정/삭제                     |

- 모든 기능은 로그인(Google OAuth) 필수
- 예약 수정은 본인만 가능, 삭제는 본인 + Admin/Owner 가능

## 페이지 구성

### 1. 메인 페이지 (`/`)

- 랜딩 페이지 (히어로 섹션 + 공지사항 안내 + 동호회 소개 + 기능 안내)
- 로그인 여부에 따라 CTA 분기 (로그인 → 예약현황 / 비로그인 → 로그인)

### 2. 로그인 페이지 (`/login`)

- Google OAuth 로그인
- 인앱 브라우저 감지 (카카오톡, 네이버, 인스타그램 등) → 외부 브라우저 유도
- 로그인 완료 시 홈으로 리다이렉트

### 3. 예약 현황 페이지 (`/reservations`) — 핵심 기능

- **캘린더 뷰**: 월간 달력, 날짜별 예약 건수 뱃지(파란색) + 행사 뱃지(오렌지, 여러날 행사는 셀 간 연결 표시) + 정기 일정 뱃지(#4eaea9)
- **리스트 뷰**: 기간별 조회 (1주/2주/1개월/커스텀)
- **예약 등록**: 날짜, 시작·종료 시간, 장소, 목적 입력
- **반복 예약**: 요일 선택 + 종료일 설정, 최대 100건 일괄 생성
- **예약 삭제**: 반복 예약의 경우 3가지 옵션 (이것만/이후 전부/전체), Admin/Owner는 타인 예약 삭제 가능
- **이벤트 표시**: 관리자가 등록한 동호회 행사 (오렌지 색상 구분, 여러날 행사 지원)
- **정기 일정**: 아카데미, 정극 연습 등 공식 일정 (#4eaea9, Admin/Owner 전용, 반복 등록/수정/삭제 지원)
- **필터**: 이용 가능한 날 / 행사만 보기 / 정기 일정만 보기 토글
- **지도 링크**: 행사 장소에 네이버지도/카카오맵 등 외부 지도 링크 연동
- **실시간 업데이트**: Firestore onSnapshot으로 다른 사용자 변경 즉시 반영

### 4. 작품 정보 페이지 (`/musicals`)

- **캐러셀 뷰**: 등록된 뮤지컬 목록을 카드 슬라이더로 표시, 선택 시 미니 모드로 전환
- **상세 패널**: 씬/넘버 아코디언, 캐릭터 목록 표시
- **작품 등록/수정**: 작품명, 이미지 URL, 캐릭터 목록 (이름/축약어/설명), 씬·넘버 구성 (Admin 전용), Table 기반 붙여넣기 기능 지원

### 5. 프로덕션 페이지 (`/productions`)

- **목록 뷰**: 공연명, 기간, 연결된 뮤지컬, 스태프, 캐스팅 보드, 공연 회차 표시
- **상세 정보**: 회차별 캐스팅 (배역 ↔ 배우 매핑), 스태프 역할 (연출/음악감독/안무/무대감독)
- **등록/수정**: 공연명, 설명, 연결 뮤지컬, 공연 기간, 공연 장소, 스태프, 회차 및 캐스팅 구성 (Admin 전용)

### 6. 공지사항 페이지 (`/notices`)

- **목록 뷰**: 페이지네이션 (10건씩), 고정 공지 상단 표시
- **상세 뷰**: 리치 텍스트(HTML) 렌더링, 기존 플레인 텍스트 하위 호환
- **작성/수정**: 리치 텍스트 에디터 (TipTap 기반)
  - 글자 크기 (4단계), 볼드/이탤릭/밑줄/취소선
  - 글자 색상 (8종 프리셋 + 커스텀 색상 선택)
  - 텍스트 정렬 (좌/중/우), 불릿 리스트
  - 키보드 단축키 (Ctrl+B, Ctrl+I, Ctrl+U 등)
- **권한**: Admin만 작성/수정/삭제 가능

### 7. 관리 페이지 (`/admin`) — Owner 전용

- 어드민 추가/삭제 (이메일 검색)
- 소유권 이전 (확인 텍스트 입력 필수)
- 전체 회원 목록 (페이지네이션, 10건씩)
- Firebase Auth → Firestore 회원 동기화

### 8. 정기공연 신청 페이지 (`/invite/[year]/[round]`) — 외부 관객용

- **공개 정보 페이지** (`/invite/[year]/[round]`): 비로그인 접근, 포스터·공연 안내·시간·장소·오시는길·회차별 캐스팅 + 신청 CTA
- **신청 페이지** (`/invite/[year]/[round]/apply`): 이름·휴대폰·회차별 인원·동반인·응원배우·좌석요청·응원메시지 입력, 개인정보 동의 필수
- **감사 페이지** (`/invite/[year]/[round]/thanks/[token]`): 신청 완료 안내 + 후원 계좌 + "후원했어요" 버튼 (32자 토큰 보호)
- **회차별 마감**: 회차 시작 시각 지나면 그 회차 자동 비활성, 모든 회차 종료 시 신청 차단
- **관리자 페이지** (`/admin/invites`): 공연 CRUD, 공개 토글, 신청자 목록·통계·항목별 답변·후원자 모아보기
- **데이터**: `invites` / `inviteRegistrations` 컬렉션, 캐스팅 사진은 `/public/invites/{year}-{round}/cast/` 정적 파일
- **무료 한도**: Firestore Spark 한도 내, 이미지 대역폭은 Vercel CDN 활용
